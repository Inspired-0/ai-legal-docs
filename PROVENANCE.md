# Provenance

## Код

Архитектура движка основана на закрытом проекте AiLawyer владельца репозитория. Для этой версии
логика была вручную перенесена и упрощена. В staging не копировались история Git, база данных,
профили провайдера, рабочие defaults, Telegram адаптер, логи и реальные документы.

Публичная лицензия MIT относится только к файлам в этом новом проекте. Перед публикацией владелец
репозитория должен подтвердить, что имеет право лицензировать перенесённую логику.

## Шаблон

`templates/synthetic-service-agreement/template.docx` создан с нуля для этого демо. Он не основан
на клиентском документе, стороннем бланке или шаблоне из закрытого проекта. Текст и оформление
можно использовать по лицензии MIT этого репозитория.

Все стороны, адреса, номера и суммы в примере вымышлены. Маркер `SYNTHETIC DEMO` есть в исходном
запросе, шаблоне и результате тестового заполнения.

## Зависимости

Проект использует сторонние библиотеки `docxtpl`, `python-docx`, `PyYAML` и `num2words`. Их права
и условия распространения задаются собственными лицензиями этих проектов.

Социальное превью `docs/social-preview.jpg` создано для этого репозитория с помощью OpenAI ImageGen. В нём нет пользовательских данных и сторонних изображений.
