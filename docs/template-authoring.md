# Как устроен шаблон

Публичный шаблон находится в `templates/synthetic-service-agreement/template.docx`. Он создан
скриптом `scripts/build_synthetic_template.py` без использования рабочих или сторонних документов.

## Слоты

Обычное поле записывается как `{{ customer_name }}`. Список услуг использует управляющие строки
`{%tr for service in services %}` и `{%tr endfor %}`. `docxtpl` повторяет строку таблицы для каждой
позиции.

Поля `service.amount`, `total_amount` и `total_in_words` не извлекаются моделью. Их рассчитывает
код в `templates/fields.py`.

## Дизайн

Шаблон использует preset `standard_business_brief` и простой вариант `memo_masthead` без линии.

- Страница Letter в книжной ориентации.
- Поля по 1 дюйму.
- Основной шрифт Calibri 11 pt.
- Межстрочный интервал 1.10 и отступ после абзаца 6 pt.
- Заголовки 16, 13 и 12 pt с цветами preset.
- Таблица имеет ширину 9360 DXA и отступ 120 DXA.
- Ширины колонок 720, 4320, 1080, 1440 и 1800 DXA.
- Внутренние поля ячеек 80, 120, 80 и 120 DXA.

Отклонения названы в скрипте как отдельные роли. Заголовок документа имеет 23 pt. Подзаголовок
имеет 14 pt. Текст таблицы имеет 10.5 pt. Маркер демо и дисклеймер выделены красным цветом риска.

## Проверка нового шаблона

1. Добавьте поле в `fields.yaml`.
2. Добавьте слот в скрипт создания шаблона.
3. Пересоберите DOCX командой `uv run python scripts/build_synthetic_template.py`.
   Команда перезаписывает версионируемый шаблон; выполняйте её только при его изменении.
4. Проверьте и очистите metadata. Ранее упомянутый `privacy_scrub.py` в этот репозиторий
   не включён. Генератор не обеспечивает очистку creator, lastModifiedBy и rsid;
   воспроизводимая очистка требует отдельного изменения. Не ослабляйте тест metadata.
5. Обновите golden структуру только после ручного ревью.
6. Запустите `uv run pytest tests/test_template_structure.py tests/test_pipeline.py`,
   затем `uv run ruff check .`, `uv run pytest` и `uv run python scripts/run_demo.py`.
   Визуально проверьте все страницы результата; автоматические тесты не проверяют верстку целиком.

Набор шаблонов содержит только синтетические договоры, реквизиты и настройки провайдера.
