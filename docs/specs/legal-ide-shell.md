# IDE как подключаемое рабочее пространство

Дата: 2026-10-30. Статус: третий модуль, проектирование после самостоятельных выпусков
MCP и плагина. Основание: [концепция](modular-legal-platform.md).

## Назначение

IDE объединяет документы дела, диалог с агентом, правовые источники и принятие правок.
Она подключает наш правовой MCP, процедуры юридического плагина и другие совместимые
модули. Пользователь может продолжать применять MCP и плагин вне IDE.

Принятый [макет](../../prototypes/legal-ide/README.md) сохраняется как основа UI.
Windows остаётся прежней целевой платформой; установщик и конкретный runtime ещё
не выбраны. Самостоятельные первые модули не ждут разработки Windows-приложения.

## Ответственность

| ID | Возможность | Граница |
| --- | --- | --- |
| IDE-01 | Дела, документы, история диалогов | Постоянное состояние принадлежит IDE, правовой корпус остаётся на MCP |
| IDE-02 | Подключение и отключение MCP | Стандартные tools и версионированные результаты, без прямого доступа к чужой БД |
| IDE-03 | Выполнение юридических процедур | Адаптер agent runtime; установка плагина другого хоста сама по себе этого не обеспечивает |
| IDE-04 | Просмотр и принятие изменений | Версия/якорь исходника, diff, применить/отклонить, undo |
| IDE-05 | Источники рядом с выводом | Точный фрагмент, редакция, статус проверки и изменившиеся основания |
| IDE-06 | Другие модули | Объявленные возможности, разрешения и понятное поведение при отключении |

Функции поиска норм и актуализации не дублируются в UI. Возможный локальный кеш
сохраняет происхождение и дату проверки; он не становится отдельной «актуальной
базой права». Локальный поиск по материалам дела решает другую задачу и добавляется
по необходимости. SQLite остаётся кандидатом для состояния IDE, без принятого решения.

## До реализации

Нужно выбрать способ исполнения агента, проверить повторное использование навыков,
определить движок DOCX/PDF, формат операций и хранение. Прежний выбор направлений
PDF и исследования лицензий сохранены как материалы, а не как закрытая приёмка.
Защищённый режим проектируется отдельно; порядок его включения в IDE пока открыт.

## Приёмка этапа

Одна задача проходит через подключённые модули от обстоятельств до сохранённого
документа. Отключение MCP сохраняет локальную работу и показывает недоступность
правовой проверки. Версия источника воспроизводится; ручная правка документа
блокирует применение устаревшего предложения. Те же MCP и процедуры продолжают
проходить самостоятельные проверки вне IDE.
