## Риски и неизвестное

- `uv` исходно не найден в PATH; установлен 0.13.1 во временное окружение, создан локальный .venv.
- В template-authoring.md упомянут отсутствующий privacy_scrub.py. Генератор сам не очищает
  все проверяемые metadata; описать ограничение, не выдавать пересборку за готовый процесс.
- Не фиксировать неподтверждённые результаты проверок или предлагаемые улучшения как готовые.

## Решения

- Сохранить существующий путь docs/architecture.md: не дублировать документ и не ломать ссылки.
- Не добавлять настройки моделей, skills, hooks и MCP без повторяемой потребности.
- Использовать имеющийся CI; новые тесты для организационной документации не нужны.
