# Аудит pravo.gov.ru и макеты юридической IDE

Дата: 2026-10-19. Статус: завершено.

## Цель

Проверить техническую возможность собственной базы из pravo.gov.ru, включая получение текстов,
редакции и обновления; создать локальный интерактивный макет универсальной Windows IDE.
Исследование источников и read-only UX-ревью делегированы. Запись в проект выполняет основной агент.

## Объем и ограничения

Текущее приложение — Python/DOCX демо. Макет изолирован в `prototypes/legal-ide/`, без изменений
конвейера и без зависимости от сервисов. Пример — синтетический IT-договор. Никаких реальных
ключей, клиентских файлов или внешних запросов из интерфейса. Редактор/LLM/правовая база имитируются.
Аудит портала — ограниченные публичные запросы без массового скачивания и обхода ограничений.

## Проверки

`node --check` для приложения/браузерной проверки; 11 групп Playwright в Chromium на macOS,
7 PNG и JSON отчета. Ошибок страницы/внешних запросов нет. Просмотрены снимки и выполнено
read-only ревью; исправлены undo, устаревший сценарий, экспорт и обработка вставки.
Windows и настоящие SDK не входят в приемку макета. Python-код не менялся.
Проверены локальные ссылки, code fences и пробелы в 32 Markdown-файлах, два JSON-файла;
ошибок нет. `git diff --check` — без замечаний. Все новые материалы добавлены в карту документации.
