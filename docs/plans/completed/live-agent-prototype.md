# Рабочий агент в прототипе IDE

Дата: 2026-10-19. Статус: завершен в описанном ниже объеме.

Пользователь выбрал совместимый Chat Completions endpoint
`http://82.112.52.41:59425/chat/completions` и `o4-mini-2025-04-16`.
Это заменяет прежний shortlist провайдеров для первого прототипа.

## Объем

Локальный сервер и существующий интерфейс: реальный вопрос с контекстом синтетического
документа, просмотр исходящего запроса, точечная замена заданных имен и обратная подстановка,
структурированные предложения правок с проверкой исходного текста и ручным принятием/отменой,
отдельный вызов проверяющего. Нет имитации подключенной правовой базы или гарантии проверки
законов. Нативные файловые движки, Windows packaging и NER остаются следующими этапами.

## Решения

Ключ только через `LEGAL_IDE_API_KEY` в окружении сервера, не в браузере/репозитории.
HTTP задан пользователем; это не защищенный канал для клиентских договоров.
Никаких произвольных URL инструментов, автоматических повторных платных вызовов,
записи оригиналов и логирования содержимого запросов. Без новых Python-зависимостей.
Старый синтетический конвейер сохраняет свои интерфейсы и инварианты.

## Результат

Запуск: [live-ide](../../runbooks/live-ide.md). 32 pytest, Ruff, 6 групп браузерных
проверок рабочего режима, 11 групп исходного автономного макета. Два настоящих вызова
в UI (основной и проверяющий), принятие/undo — успешно. Отдельный короткий API smoke также
успешен без ключа. API сообщает `openai/gpt-6-sol` вместо запрошенного `o4-mini-2025-04-16`;
UI явно показывает расхождение, необходимо проверить маршрутизацию прокси.

Read-only ревью в свежем контексте: устранены применение пакета после изменения соседнего
пункта, статическое основание рядом с живой правкой и гонка списка замен во время preview.
Браузер проверен на macOS; Windows не проверялся. Нативные движки, RAG/источники,
автоматическое распознавание ПДн и сохранение документов остаются следующим этапом.
