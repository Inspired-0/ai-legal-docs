# Удаление неактуальной документации

Дата: 2026-10-31. Статус: завершено.
Основание: прямой запрос владельца; действующая [концепция](../../specs/modular-legal-platform.md).

## Цель и критерии завершения

Удалить документы отменённого единого IDE MVP и планы подключения платных правовых
источников. В навигации остаются действующие требования, исследования для новых
модулей и инструкции к существующему коду. Нет ссылок на удалённые файлы.

## Исследованные документы и границы

Прочитаны INDEX, CURRENT_STATE, архитектура, требования модулей, ссылки на прежнее
видение/MVP и материалы платных API. Рабочее дерево уже содержит изменения предыдущих
задач; сброс Git не применяется. Код, прототипы и инструкции их запуска сохраняются.
Будущая псевдонимизация остаётся действующим отложенным требованием.

## Решения и проверки

Документы работающего DOCX-демо, IDE-прототипа и RAG-пробы сохраняются вместе с
результатами их испытаний. Исследования официальных источников и newsBot используются
новым MCP. Старые спецификации и планы не возвращаются в архив внутри репозитория.
Временные копии удалённых материалов сохранены вне репозитория в
`/private/tmp/ai-legal-docs-docs-cleanup-20261031` для восстановления незакоммиченных версий.

Код не менялся; pytest/Ruff не запускались. Python-проверка Markdown-ссылок, якорей
и code fences прошла без ошибок, как и `git diff --check`. Хеши 61 файла кода, тестов,
шаблонов, прототипов и сохранённых инструкций совпали с началом задачи.
Итоговые числа проверки документации записаны в CURRENT_STATE. Независимого ревью не было.

## Следующий шаг

Удалены семь документов и пустой каталог заменённых планов. Навигация и текущее
состояние очищены, полезные исследования и инструкции сохранены. Дальнейшая работа:
подготовить M1.0/M1.1 по [дорожной карте](../active/modular-platform-roadmap.md).
