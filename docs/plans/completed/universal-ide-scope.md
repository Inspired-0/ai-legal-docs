# Универсальное ядро IDE и защита данных

Дата: 2026-10-19. Статус: проектирование по уточнениям завершено; реализации нет.

## Цель

Внести ответы владельца в vision: универсальный коммерческий продукт для Windows,
IT/закупки по 44-ФЗ/223-ФЗ как первые профили, локальная обратимая замена данных до агента.
Учесть последующие уточнения: работа от контекста клиента без обязательного документа,
RAG, быстрый конструктор навыков и законодательная база с первого продуктового релиза.

## Риски

Обратимость не равна полной анонимности. Тендерный номер, URL и уникальное ТЗ могут раскрыть
участников. Избыточное удаление дат/сумм/предмета ухудшает юридический анализ. Нужно отдельно
проверять отсутствие утечек, восстановление правильных сущностей и сохранение смысла.
