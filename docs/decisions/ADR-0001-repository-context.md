# ADR-0001: общий контракт агентов и память в docs

Дата: 2026-10-18. Статус: принято в рамках настройки workflow по запросу владельца.

## Контекст

Небольшое Python-демо уже имеет README, архитектуру, тесты и CI. Нужен переносимый контекст для
Codex и Claude Code согласно [инструкции владельца](https://app.notion.com/p/3e2b3ded4f0881eaace3d6e3f19815fa).

## Решение

Общие постоянные правила находятся в корневом AGENTS.md, CLAUDE.md отсылает к нему.
INDEX направляет к контексту продукта, архитектуре, требованиям, планам и runbooks.
CURRENT_STATE содержит только текущую точку продолжения и проверенные результаты.
Существующий `docs/architecture.md` сохраняет имя и ссылки; копия ARCHITECTURE.md не создаётся.

## Альтернативы

- Полный универсальный шаблон в AGENTS: слишком много контекста для маленького демо.
- Отдельные правила для каждого агента: риск расхождения требований и команд.
- Все каталоги и конфигурации из примера заранее: нет подтверждённой потребности.

## Последствия

Skills, hooks, MCP и настройки моделей добавляются при конкретной повторяемой необходимости.
Существующий CI остаётся механизмом проверки Python-кода. Текущая задача добавляет документацию,
не меняя продуктовые интерфейсы, зависимости и шаблон. Документы требуется обновлять вместе
с изменениями контрактов; завершённые планы сохраняются отдельно от активного контекста.
