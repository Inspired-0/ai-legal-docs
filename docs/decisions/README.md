# Архитектурные решения

ADR нужен при изменении границ модулей, важной зависимости, устойчивого контракта или выборе
с существенными альтернативами. Не создавать ADR на каждую локальную правку.

Использовать [TEMPLATE.md](TEMPLATE.md), имя `ADR-NNNN-short-name.md`, дату и статус.
При смене решения новый ADR ссылается на заменяемый; история причин сохраняется.

- [ADR-0001: контекст репозитория](ADR-0001-repository-context.md).
- [ADR-0002: самостоятельные правовой MCP и агентный плагин](ADR-0002-independent-legal-modules.md).
- [ADR-0003: составной поиск в MCP, оценка применимости у агента](ADR-0003-compound-legal-search.md).
