# Текущее состояние

Обновлено: 2026-10-31.

## Направление и следующий этап

Действующее направление: самостоятельный правовой MCP для ChatGPT/Claude,
юридический плагин для Codex/Claude Code, затем IDE с подключаемыми модулями.
[Концепция](specs/modular-legal-platform.md) и
[дорожная карта](plans/active/modular-platform-roadmap.md) задают требования и порядок.
Новые модули пока не реализованы.

Владелец подтвердил:

- Широкий федеральный корпус: кодексы, законы, постановления и ведомственные акты.
  Ежедневные обновления и доступный агенту журнал, основа сбора из newsBot.
- Составной поиск в MCP: подбор регулирования по вопросу и оснований ограничений
  по формулировке. Сервер собирает доказательства, агент оценивает применимость;
  наш плагин и генеративная модель на сервере для поиска не нужны.
  [Принятое решение](decisions/ADR-0003-compound-legal-search.md).
- Только бесплатные правовые источники. Размещение MCP на VPS; рекомендуемые ресурсы
  8 vCPU/32 ГБ RAM/300-500 ГБ NVMe пока не проверены нагрузкой.
- Плагин работает самостоятельно с материалами пользователя. Наш MCP необязателен.
  Первыми идут создание и проверка договоров с DOCX; полный каталог claude-for-legal
  включён в дальнейшие этапы, включая tracked changes, комментарии и табличные результаты.
- Обычный файловый режим плагина; защищённый режим с псевдонимизацией позже.
- Собственный исследовательский агент отложен. Отдельная проверка подготовленного
  правового результата сохраняется; юристы подключатся к приёмке позже.

Все три раунда [интервью](investigations/modular-platform-interview.md) завершены.
Рекомендация стека: Python MCP, отдельный updater, PostgreSQL/FTS/pgvector и неизменяемые
снимки источников. Выбор модели embeddings и ранжирования требует новых измерений.
[Каталог claude-for-legal](investigations/claude-for-legal-capabilities.md) содержит
150 файлов навыков и 10 агентов из 12 основных пакетов. Платный CoCounsel исключён.
Исследование и документы: [завершённый план](plans/completed/modular-platform-discovery.md).

## Что уже работает

| Часть | Реализовано | Ограничения |
| --- | --- | --- |
| DOCX-демо | Извлечение известных полей, расчёты кодом, заполнение и проверка шаблона | Один синтетический договор; статусы done/needs_input/failed; не сервис реальных договоров |
| IDE-прототип | Макет, API-диалог, preview, предложения правок, принятие/отклонение/undo, отдельный повторный анализ | Синтетический текст; история в памяти страницы, без нативного DOCX/PDF, NER и действующего правового поиска |
| RAG-проба | ЕБПИ, статьи/фрагменты, PostgreSQL/pgvector, проверка цитат, сравнение поиска | Два акта и три редакции; нет продуктового MCP, полного корпуса и проверки применимости по датам |

Запуск и границы: [архитектура](architecture.md), [runbook IDE](runbooks/live-ide.md),
[DOCX-демо](specs/synthetic-document-pipeline.md), [RAG-проба](investigations/shared-legal-rag-spike.md).
Дизайн IDE принят. Различие запрошенного имени модели и имени в ответе выбранного API
подтверждено владельцем как ожидаемое; повторное согласование не требуется.

В RAG-пробе 1522 статьи с учётом редакций и 2030 фрагментов. На 12 вопросах попадание
ожидаемой статьи в первую пятёрку: текстовый поиск 6/12, семантический 10/12, RRF 9/12.
Простое объединение выдач иногда ухудшает результат. Эти числа не оценивают качество
широкой федеральной базы или её скорость на VPS.

Полезные материалы для продолжения: [официальные источники](investigations/open-legal-sources.md),
[аудит портала](investigations/pravo-portal-audit.md), [newsBot](investigations/newsbot-sources.md),

## Открытые вопросы и ограничения

- Каталог федерального покрытия, глубина истории, условия массового доступа к бесплатным
  источникам, авторизация, провайдер/тариф VPS, команда и нагрузка ещё не определены.
- Подключение нового MCP в ChatGPT/Claude и установка плагина в двух хостах не испытаны.
  Сохранность произвольного Word/PDF и расписание фоновых процедур требуют разработки.
- Схемы составного поиска, правила меток ограничений, лимиты и показатели качества
  нужно проверить на M1.0/M1.4. Их нагрузка не измерена прежней RAG-пробой.
- Прототип проверяющего не получает законы самостоятельно и не подтверждает юридическую
  достоверность. Технические испытания модулей не заменяют последующую приёмку юристами.
- Генератор шаблона пока не очищает все metadata; инструкции в
  [template-authoring](template-authoring.md). Typecheck не настроен; ограничения
  исходного демо описаны в [limitations](limitations.md).
- В рабочем дереве остаются незакоммиченные изменения предыдущих задач; Git не сбрасывался.
