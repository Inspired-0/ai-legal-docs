# Интервью о самостоятельных юридических модулях

Дата: 2026-10-30. Статус: все три раунда получены и внесены в документы.
Основание: изменение концепции владельцем в текущей сессии.

## Подтверждённые решения

| ID | Вопрос | Ответ владельца | Следствие |
| --- | --- | --- | --- |
| INT-01 | Как разделить продукт | Самостоятельный правовой MCP, отдельный юридический плагин, затем IDE | У каждого модуля отдельная поставка и приёмка; первые два полезны независимо |
| INT-02 | Где сначала подключают MCP | Общий сервер для ChatGPT и Claude | Удалённый HTTPS endpoint, серверный корпус и фоновые обновления |
| INT-03 | Широта первого корпуса | Широкая база законодательства РФ, затем углубление качества | Выпуск не ограничивается демонстрацией двух кодексов |
| INT-04 | Состав широкого корпуса | Федеральное законодательство: кодексы, законы, постановления и ведомственные акты | Региональное/муниципальное право и практика не являются обязательным первым охватом |
| INT-05 | Самостоятельность плагина | Собирает обстоятельства, готовит и проверяет документы по материалам пользователя; MCP добавляет поиск/проверку норм | Нет обязательного аккаунта или подключения к нашему MCP |
| INT-06 | Источник системы обновлений | newsBot; прежнее упоминание AccountAnalysis исправлено | Использовать правовые адаптеры, добор и watch редакций newsBot |
| INT-07 | Защита данных в первом плагине | Обычная работа с файлами в агенте; защиту отдельным режимом позже | Псевдонимизация до первого доступа модели не является условием этого выпуска |
| INT-08 | Обновления первого MCP | Ежедневное обновление базы и доступный агенту журнал изменений | Планировщик работает без чата; журнал доступен через MCP, персональные рассылки позже |
| INT-09 | Автономность плагина и исследовательский агент | Плагин самостоятелен; собственного исследователя пока не делать, проверить наличие в claude-for-legal | Наш MCP необязателен; обычные исследовательские процедуры сохраняются, отдельный агент отложен |
| INT-10 | Сценарии плагина | Создание и проверка договоров с DOCX, а также все возможности claude-for-legal | Договоры первыми; весь каталог функций входит в дорожную карту и приёмку, включая другие практики |
| INT-11 | Приёмка, размещение и источники | Юристы проверят позже; сервер на VPS, нужны характеристики; платные источники недопустимы | Технические этапы идут без немедленной разметки юристом; только бесплатные правовые данные; подготовлен расчёт VPS |

Решение INT-07 изменяет прежнее обязательное требование приватного контекста для
первого плагина. Оно не разрешает добавлять клиентские документы в репозиторий,
смешивать дела в общем корпусе или считать существующий синтетический прототип
готовым для рабочих конфиденциальных файлов.

## Результат проверки гипотез

Проверка upstream выявила 12 основных пакетов, 150 файлов навыков и 10 агентов.
Универсального исследователя в основных пакетах не найдено; есть план исследования
`research-start` и внешний CoCounsel Deep Research с платной подпиской для права США.
Последний исключён ограничением владельца. Собственный исследователь остаётся
отложенным. Прежний отдельный проверяющий результата сохраняет свою роль.

Полный каталог и зависимости: [claude-for-legal](claude-for-legal-capabilities.md).
Рекомендация для VPS: 8 vCPU, 32 ГБ RAM, 300-500 ГБ NVMe; технический пилот возможен
с меньшими ресурсами. Это [расчёт](legal-mcp-vps.md), не выбранный тариф и не нагрузочное
испытание. Состав команды и бюджет инфраструктуры владелец пока не называл.

## Решения для следующих этапов

Уточнять перед соответствующей реализацией, без повторного интервью по INT-01…INT-11:

- Историческая глубина базы и критерий достаточного федерального покрытия.
- Закрытый пилот или публичный доступ, схема авторизации и ограничения использования.
- Техническая доступность бесплатных источников, правила массового доступа и измеримый
  срок от доступности документа у источника до индекса.
- Поддерживаемые конструкции DOCX и тестовые файлы; создание и проверка уже выбраны,
  tracked changes и комментарии нужны для договорного сценария upstream.
- Состав команды, бюджет VPS/агентного хоста и ожидаемая одновременная нагрузка.
- Состав юридической выборки, ответственный и пороги на последующем этапе проверки.
- Условия будущего защищённого режима и платформы IDE.
