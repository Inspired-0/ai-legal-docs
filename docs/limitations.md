# Ограничения

Проект решает одну задачу. Он заполняет синтетический договор оказания услуг.

- Текст шаблона не является юридической консультацией.
- Шаблон не предназначен для реальной сделки.
- Извлечение LLM может ошибаться и требует проверки пользователем.
- JSON адаптер не отправляет запрос сам. Сетевой клиент должен добавить пользователь проекта.
- Встроенное форматирование денег поддерживает простой рублёвый пример.
- Сумма прописью не склоняется по всем правилам юридических документов.
- Проект не хранит версии документов и не ведёт журнал действий.
- Telegram интеграции, базы данных и рабочие профили намеренно не включены.

Для реальной системы нужны проверенные шаблоны, контроль доступа, политика хранения, аудит,
защищённый провайдер LLM и юридическая проверка каждого сценария.
