# Локальная разработка и проверки

## Установка и запуск

Нужны Python 3.11+ и uv. Все команды выполнять из корня репозитория.

```bash
uv sync --locked --dev
uv run python scripts/run_demo.py
```

Демо использует `MockExtractor` и `examples/expected-fields.json`; ключи и сеть для самого
демо не нужны. Ожидается `PipelineStatus.DONE` и `out/synthetic-service-agreement.docx`.
Синхронизация зависимостей может потребовать сеть. `--locked` не разрешает незаметно менять lock.

Если `uv` отсутствует, установи его в локальное или временное окружение и добавь его каталог
в PATH; не меняй зависимости проекта ради инструментов запуска. В ограниченной среде можно
направить кеш в репозиторий: `UV_CACHE_DIR="$PWD/.uv-cache" uv sync --locked --dev`.
Если установка недоступна, запиши конкретную причину в CURRENT_STATE, не объявляй проверки успешными.

## Проверки по изменению

| Изменение | Минимальная проверка |
| --- | --- |
| Документация | Локальные ссылки, пути/команды по коду и CI, `git diff --check` |
| Python | Близкие тесты при разработке, затем `uv run ruff check .` и `uv run pytest` |
| Поля/расчёты/рендер | Тесты полей и конвейера, затем общие проверки и demo |
| DOCX/генератор | Общие проверки, golden/metadata, demo и визуальное ревью страниц |
| Упаковка/зависимости | Locked sync, общие проверки, `uv build` |

```bash
uv run ruff check .
uv run pytest
git diff --check
```

CI выполняет locked sync, Ruff и pytest. Отдельный typechecker не подключён.
`uv run ruff format <paths>` форматирует выбранные файлы; не переформатируй весь проект
в несвязанной задаче. `uv build` создаёт артефакты в игнорируемом `dist/` и не публикует пакет.

## Диагностика результата

- `needs_input`: изучить `missing` и YAML; рендер не выполнялся, старый файл может остаться.
- `failed`: изучить `issues`; файл существует, но не прошёл проверки.
- Исключение: проверить извлечение, входные файлы, расчёты, рендер и доступ к каталогу.
  Не предполагать, что конвейер преобразует любую ошибку в статус.

Для изменений шаблона следовать [template-authoring.md](../template-authoring.md).
Результаты и локальные кеши игнорируются Git; реальные документы и секреты не использовать.
