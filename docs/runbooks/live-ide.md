# Запуск рабочего AI-прототипа

Из корня репозитория, Python 3.11+ и установленные зависимости проекта:

```bash
uv sync --locked --dev
uv run python scripts/run_ide.py
```

Открыть **http://127.0.0.1:8765**. Альтернатива при готовом окружении macOS/Linux:
`.venv/bin/python scripts/run_ide.py`; Windows: `.venv\Scripts\python.exe scripts/run_ide.py`.
Порт меняется через `--port 8766`. Сервер слушает только 127.0.0.1; `localhost` как Host
намеренно не принимается. Остановка Ctrl+C. Это локальный браузерный прототип, не EXE-сборка.

## Подключение

По явному выбору пользователя:

- Endpoint: `http://82.112.52.41:59425/chat/completions` — полный адрес, без добавления `/v1`.
- Запрошенная модель: `o4-mini-2025-04-16`.
- Ключ необязателен; на проверке 19.10.2026 запрос без ключа прошел.
- Переменные процесса: `LEGAL_IDE_ENDPOINT`, `LEGAL_IDE_MODEL`, `LEGAL_IDE_API_KEY`.
  `.env` автоматически не загружается; не вводить ключ в чат, Git или браузер.

В фактическом ответе API на проверке указано **`openai/gpt-6-sol`**. В запросах остается
выбранное имя; UI сообщает о расхождении. 22.10.2026 пользователь подтвердил, что такое
соответствие имён ожидаемо; отдельная диагностика маршрутизации не требуется.
Код не подменяет модель и не включает fallback.

Адаптер использует `max_completion_tokens`, без `temperature`/старого `max_tokens`,
`stream=false`, `store=false`, JSON object output. Схема сверена с
[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)
и [страницей o4-mini](https://developers.openai.com/api/docs/models/o4-mini).
Отправленный `store=false` не подтверждает отсутствие логов у стороннего прокси.
HTTP не шифрует данные/ключ; прототип предназначен только для синтетических запросов.

## Проверочный сценарий

1. Открыть договор. Написать: «Мы заказчик Альта. Предложи в пункте 4.2 изменить
   5 рабочих дней на 10. Не ссылайся на законы».
2. Кнопка отправки сначала показывает полный JSON запроса. Значения из списка «Защита»
   заменены локальными токенами. Затем «Отправить модели» выполняет реальный вызов.
3. Получить ответ и предложения. «Принять правку» изменяет текст в памяти страницы;
   «Отклонить» сохраняет исходный текст. Можно отменить последнюю AI-правку.
4. «Проверить ответ вторым агентом» создает новый предпросмотр и отдельный запрос,
   без истории основного чата. Правовые источники этому проверяющему недоступны.
5. Ручное изменение любого пункта или добавление контекста блокирует старый пакет правок.
   Последовательное принятие нескольких правок одного пакета разрешено. Undo не удаляет
   ручное изменение поверх принятой правки.
6. «＋» в чате создает новый диалог по открытому документу; предыдущая переписка сохраняется
   в разделе «Все диалоги». Там доступны поиск по названию/документу/сообщениям и дата
   последнего сообщения. Выбор диалога восстанавливает документ, страницу PDF, переписку,
   черновик, результат второго анализа и предложения. Текст документа общий для его диалогов:
   это не восстановление старой версии; устаревшие предложения блокируются.
7. Выбор другого документа открывает его последний диалог или создает пустой. Истории
   разных документов не передаются модели вместе. Во время запроса смена диалога/документа
   блокируется; просмотр списка доступен. Кнопка «В контекст договора» у PDF добавляет
   фрагмент страницы 1 в последний диалог по договору и открывает его. Новые диалоги
   этот фрагмент автоматически не наследуют. При длинной истории начать новый диалог:
   лимит — 12 сообщений на запрос.

Отправляется текст выбранного документа; для PDF-макета — открытая страница, для фрагмента
ТЗ — явно добавленный контекст текущего диалога. Нет чтения локальных папок или скрытой загрузки файлов.
Неудачный запрос не повторяется автоматически. Ошибка структуры/обрезанный ответ не
порождает применимых правок. Предпросмотр одноразовый и доступен для отправки 10 минут.
Смена контекста или списка замен до отправки требует нового предпросмотра.

## Границы

- Замена **точных строк**, не автоматическое обнаружение ПДн. Склонения, реквизиты,
  косвенные идентификаторы и новые имена автоматически не распознаются. Таблица подстановок
  остается в памяти локального процесса; восстанавливается текст ответа и правок.
- История, редактор и параметры замены не сохраняются после перезагрузки. Экспорт только TXT.
  DOCX/PDF в обозревателе — синтетические HTML-представления, не нативные файлы.
- RAG, загруженные законы, подтвержденные цитаты и проверка актуальной редакции отсутствуют.
  Второй вызов ищет ошибки в рассуждении, но не доказывает правовую достоверность.
- Навыки/поиск источников остаются макетом; их демонстрационные карточки не обосновывают
  реальные ответы. Статическое основание у пункта договора в рабочем режиме убрано.
- Нет доступа модели к shell, файлам, произвольным URL и другим инструментам.
- Windows, установка desktop-пакета, коммерческая готовность и качество юрвыводов не испытаны.
