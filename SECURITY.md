# Обработка данных

Публичная версия работает только с синтетическими данными. Реальные договоры, реквизиты, персональные данные и адвокатская тайна не входят в сценарий демо.

В репозитории нет ключей и рабочего LLM endpoint. Секреты подключаются через переменные окружения. Запросы и готовые документы не попадают в журналы приложения.

Сообщения о найденных секретах и личных данных обрабатываются через приватный контакт в GitHub профиле.
