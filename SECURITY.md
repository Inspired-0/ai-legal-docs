# Security

Публичная версия работает только с синтетическими данными. Не отправляйте в демо реальные договоры,
реквизиты, персональные данные или адвокатскую тайну.

В репозитории нет ключей и рабочего LLM endpoint. Настоящие секреты нужно передавать только через
переменные окружения. Не сохраняйте запросы и готовые документы в логах.

Если вы нашли секрет или личные данные, не создавайте публичный issue. Свяжитесь с владельцем
репозитория через контакты в GitHub профиле.
